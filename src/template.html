Intrinsic properties

Eg(T) = Eg0 − αT² / (T + β) (Varshni)
Nc,v = 2.509×10¹⁹ (m*)3/2 (T/300)3/2 cm⁻³, ni = √(NcNv) · exp(−Eg/2kT)
Ei = (Ec + Ev)/2 + (kT/2) ln(Nv/Nc)

Fermi level (solved numerically from charge neutrality)

p + ND+ = n + NA−, ND+ = ND / [1 + 2 exp((EF − ED)/kT)], NA− = NA / [1 + 4 exp((EA − EF)/kT)]
n = Nc 𝓕1/2((EF − Ec)/kT) — Fermi–Dirac (Aymerich-Humet approx.) or Boltzmann exp(·)

Built-in voltage (homo- and heterojunction, Anderson model)

qVbi = Φp − Φn = [χp + Eg,p − (EF − Ev)p] − [χn + (Ec − EF)n]
Homojunction, Boltzmann: Vbi = (kT/q) ln(NAND / ni²)
ΔEc = χp − χn, ΔEv = (χp + Eg,p) − (χn + Eg,n)

Abrupt junction

xn = √{ 2εpεnNA(Vbi − V) / [qND(εpNA + εnND)] }, xp = xnND/NA, |E|max = qNDxn/εn
φ(x) = qNA(x + xp)²/2εp for −xp ≤ x < 0; φ(x) = (Vbi − V) − qND(xn − x)²/2εn for 0 ≤ x ≤ xn

Linearly graded junction

W = [12ε(Vbi − V)/qa]1/3, Vbi = (2kT/q) ln(aW/2ni), |E|max = qaW²/8ε

p–i–n junction (ideal intrinsic layer of thickness d)

Vbi − V = qNAxp²/2εp + qNAxpd/εi + qNDxn²/2εn, NAxp = NDxn (solved as a quadratic in xp)
Ei = qNAxp/εi (uniform), W = xp + d + xn, C/A = (xp/εp + d/εi + xn/εn)−1 → εi/d for d ≫ xp, xn
VBR + Vbi ≈ Ecritd (thick i-layer); Jgr0 = q(ni,pxp + ni,id + ni,nxn)/2τ0

Capacitance, current, breakdown

C/A = (xp/εp + xn/εn)−1
J = q(Dnnp0/Ln + Dppn0/Lp)(eqV/kT − 1) + (qniW/2τ0)(eqV/2kT − 1), L = √(Dτ), D = μkT/q
VBR ≈ (εEcrit²/2q)(1/NA + 1/ND) − Vbi (homojunction)
μ(N,T) = [μmin + (μmax − μmin)/(1 + (N/Nref)a)]·(T/300)−γ (Caughey–Thomas)
Assumptions: 1-D, depletion approximation, no interface states, polarization charge or tunneling; deep dopants are fully ionized inside the depletion region (DC). Ecrit is treated as doping-independent.
